# Поиск — что готово и что зависит от финального домена

- У страниц есть смысловые title/description/H1, текстовые внутренние ссылки и alt реальных товаров. Store JSON-LD содержит подтверждённые контакты/магазин; Product — реальный товар, SKU, бренд и изображение. Цены/остатки не выдаются за подтверждённые сервером offers; обещаний rich results нет.
- Preview закрыт от индексации метатегом noindex. robots.txt в GitHub project-подкаталоге не заменяет robots.txt корня github.io; решающий preview-сигнал — meta noindex. Пустой sitemap не содержит выдуманного production-домена.
- Финальный домен ещё не подтверждён. Перед production распаковкой пересобрать **тот же единственный ZIP** командой `python3 production/package.py --origin https://ФИНАЛЬНЫЙ-ДОМЕН` (IDN использовать в punycode). Она выставит static canonical/OG финального домена, index,follow, корневые robots.txt/sitemap.xml. Пароли и verification values не нужны. Без --origin пакет остаётся staging/noindex.
- **Ограничение текущей архитектуры:** страницы каталога открываются через #/… . Их нельзя считать отдельными надёжно индексируемыми URL и включать hash-адреса в sitemap. Для полноценного товарного SEO потребуется согласованный этап обычных URL + prerender/SSR с серверными 200/404 и canonical каждой страницы. Маршрутизация в этом визуальном проходе сохранена. [Google: fragment URLs](https://developers.google.com/search/docs/crawling-indexing/javascript/fix-search-javascript).
- После запуска домена: проверить HTTPS/redirects/robots/canonical, зарегистрировать домен в Яндекс Вебмастере и Google Search Console под аккаунтом владельца; добавить только выданную ими DNS/HTML verification; проверить rendered HTML/URL Inspection; отправить реальный sitemap. [Google: sitemap](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap).
- После будущего перехода на обычные URL: добавить реальные category/product URL в sitemap, проверить их HTTP status, уникальные title/description/canonical и structured data. Не создавать сотни пустых страниц/городов/keyword landing pages.
- Реклама, аналитика, бюджет, регионы, ассортимент и доступ к учётной системе согласуются отдельно. Интеграции с МойСклад и рекламных пикселей сейчас нет.
